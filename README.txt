THE DHRUV TEST — WEBSITE FILES

Files:
- index.html: complete responsive animated site; no build tools required.

How to use:
1. Open index.html in a browser to test it.
2. Upload index.html to GitHub Pages, Netlify, or another static hosting service.
3. Open the published link on phone or PC.

Important:
- The "one time only" lock uses browser localStorage. It prevents repeat attempts in the same browser profile, but it is not a secure global one-time system: clearing browser data, using private browsing, or opening another device can reset/bypass it.
- To enforce one attempt per person across all devices, the site needs a backend/database and user identity/authentication.
- Questions are general friendship questions because Dhruv's personal preferences and memories weren't supplied. Edit the `questions` array in index.html to personalize them.
- The Google Fonts import requires internet; system fonts will be used if unavailable.
